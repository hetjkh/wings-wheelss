# Mobile subject layers v2

Created using the built-in image generation tool, editing the corresponding mobile-v1 portrait. Transparent WebP files are saved in `public/images/africa-mobile/`, and PNG originals are retained in this folder. These layers move independently above the existing scenery and behind the foreground frame on phones.

## business-subject-mobile-v2

Use case: background-extraction. Edit the supplied business travel photograph into a foreground-only layer. Preserve exactly the same people or animals, identities, clothing, poses, proportions, fine edges, and their position on the original portrait 1024x1536 canvas. Keep all subjects and any luggage held by them. Remove the entire surrounding environment, sky, scenery, architecture, plants and floor and replace it with genuine transparent alpha. Preserve transparent holes between limbs and between subjects. No background, no ground rectangle, no shadows extending beyond feet, no extra objects, no cropping. This is a clean transparent photographic subject layer for independent parallax animation.
