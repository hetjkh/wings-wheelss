# RomanKnows presentation artwork

Created with the built-in image_gen tool. These assets are conceptual illustrations, not security findings or product screenshots. Actual application screenshots in the presentation were extracted from the supplied project report.

The redesigned presentation uses SF Pro Display for headings and body text, with Consolas for metadata. Layouts, text, and diagrams are native editable PowerPoint elements. The PDF preserves the rendered typography.
